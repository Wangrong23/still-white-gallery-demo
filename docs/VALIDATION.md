# MVP 验证记录

环境：Windows；Node 22+；Three.js 0.180.0；ws 8.21.3；桌面 Chromium 内嵌浏览器。

## 自动测试

- `node scripts/check.js`：所有 JS 模块语法检查。
- `node --test tests/core.test.js tests/network.test.js`：游戏规则及真实 WebSocket 集成用例通过，具体数量以当前测试输出为准。
- `node scripts/build.js`：生成离线依赖齐全的浏览器资源目录。
- 依赖审计：升级 ws 后复核，无已知漏洞；隔离目录 `npm ci` 安装恰好两个依赖成功。

## 实际运行

- HTTP `/health` 返回 200；首页和 Three 模块正常加载；浏览器错误日志为空。
- 以凶手进入单人演练；F10 进入中央展台。HUD 显示 STILL、SPOT 0；人物一直存在。
- 高太阳时刻，人物与展台产生短影。连续 F3 后，太阳降至约 23° 并横移；同一人物的影子明显变长、转向，墙和其他雕塑的阴影也同步变化。
- Tab 切到警探、F4 进入 SUNSET，之后 NIGHT / RUN；画面变暗，锥形手电照亮前方且周边仍黑暗。
- 夜间计时结束显示 SURVIVED / DETECTIVE WINS，能返回菜单。
- 浏览器双窗口：点击 HOST 生成房间码；第二窗口 JOIN 同一码，自动获得另一角色；两窗口分别显示 DETECTIVE / KILLER 并进入同一局 DAY。双 WebSocket 权威状态和双方重开另有真实连接集成测试。

## 实测边界

尚未进行两个真人在互联网延迟下的完整 7 分钟对局，也未完成长时间服务器负载测试。浏览器画面检查验证了真实阴影机制，不等于藏点与胜率已经平衡。公网部署需要支持长驻 Node + WebSocket 的运行环境。


## 2026-09-05 试玩反馈修复

- 新增近身检查、无弹抓捕、检查中断与遮挡测试；假人碎裂、碰撞移除、贴面弹孔、警戒触发 / 过期、快照插值测试。
- WebSocket 集成覆盖双方同步假人碎裂、警戒、无弹抓捕；重开清空残骸与警戒状态。
- 在 Codex 内嵌浏览器 1280×720 验证了真实 Gallery 渲染：假人消失并留下落地碎块；假人和空射不产生弹孔；墙面弹孔为贴面圆片；重开恢复假人并清空弹孔；警戒与触发提示可见。8 项浏览器断言通过，控制台无错误或警告。
- 同一验证视角测得 80 个预热后帧间隔中位数约 5.0ms、P95 约 5.1ms，绘制调用 185。这只是当前机器的单一测试视角，不能代表所有设备或真人联网体验。
- 渲染优化：静态轮廓线合批、太阳阴影从 4096 降为 2048、HUD 更新限为 15Hz、缓存陪练寻路可通行网格。警探相机取消步行上下抖动；第三人称镜头避障后平滑拉远。
- 联机采用 100ms 快照缓冲插值，保持服务器状态不变；尚未实现本地移动预测，真实高延迟双人试玩仍需验证。


## 2026-09-06 屏息交互调整

- 15 秒气量、1 秒回气延迟、5 秒耗尽冷却；重新开始至少需要 3 秒气量。持续按住直到耗尽仅产生一次喘气，过早按键须松开再试。
- 回归覆盖连续耗尽、冷却恢复、反复点按、动画起停连续性、权威命中与插值位移一致性、屏息延缓抓捕及切换屏息无法重置检查进度、隔墙声音衰减、日落停止和重开复位。
- 普通呼吸约 1.2 秒识破；持续屏息或假人约 3.6 秒检查。WebSocket 集成验证双方均收到屏息和检查进度，松开后加速完成无弹抓捕，重开清空屏息锁定。
- 浏览器真实游戏 HUD 验证：气量上限 15 秒；低气量显示剩余秒数、橙色条和松开提示；耗尽显示 5 秒倒计时及必须松开空格的提示。验证时控制台无错误和警告。
- 静止仍为原有 12 个固定藏点；自由静止尚未实施。
