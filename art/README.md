# Noir art sources

Direction: monochrome, minimal, slightly unsettling; 1930s Art Deco exhibition and crime-film lighting.

- `noir-parts.blend`: original low-poly mesh templates, made in Blender 5.0.1.
- `../scripts/make-noir-assets.py`: reproducible source for the Blender scene, runtime geometry module; also invokes the audio generator.
- `../client/noir.js`: original canvas exhibition prints and instanced skylight strips.
- `../client/assets/`: generated runtime meshes and heel, revolver, plaster and bell sounds. Build copies these into `dist/client/assets`.

No third-party meshes, recordings, fonts or textures were downloaded. Meshes, prints and procedural effects are project-authored. Closing speech is synthesized using installed Microsoft desktop voices, not a project-authored voice or an actor recording; see `announcements.json` for exact voices and text. Rebuild using Blender's background mode and the generator script. Browser users do not need Blender.

The runtime uses connected shoulder/elbow and hip/knee chains, with walking blend and pose transitions shared by rendering and hit detection. It is still a segmented character, not a skinned skeleton. Meshes fit the existing unit hit bounds; killer and decoys share templates and materials. Printed figures are decorative. Collision still uses oriented boxes, including approximate heads. The `.blend` stores unit templates (overlapping at the origin); select a named object and isolate it to edit. Re-export changes through the generator or extend its profiles.

Footsteps (three variants), gun, breakage (two variants), bell and the stereo room impulse are generated by `python scripts/make-noir-audio.py`. Breath, heartbeat and room noise remain Web Audio synthesis. Run `powershell -File scripts/make-announcements.ps1` on Windows with the voices listed in `announcements.json` to regenerate the English closing WAV. The runtime adds a band-limited loudspeaker effect and restrained convolution reflections. The broadcast stays English regardless of UI language. The old Chinese WAV is retained only as an unused historical asset. Missing speech WAVs fall back to English browser TTS, or just the bell if speech is unavailable. The impulse is synthetic and shared across rooms, not measured acoustic simulation. Final performed voice acting, motion capture and multiplayer balance remain open.

Gameplay constraint: wall surfaces must remain uninterrupted and monochrome. Do not add contrasting skirting, wainscoting or trim. Daylight shading uses no ambient fill and a shared linear-light shadow floor of 0.028 for characters and architecture; never highlight the local killer independently.


Copy direction: restrained gallery notices and brief noir observations. In-round messages describe the immediate event; exact timings and recovery rules belong in Field Notes. Keep keys, room codes and connection errors legible. Atmospheric copy must not imply a real opponent is watching when the game has not established that. Match Chinese and English meaning without forcing literal translation.
