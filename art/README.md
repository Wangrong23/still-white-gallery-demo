# Noir art sources

Direction: monochrome, minimal, slightly unsettling; 1930s Art Deco exhibition and crime-film lighting.

- `noir-parts.blend`: original low-poly mesh templates, made in Blender 5.0.1.
- `detective-noir.blend`: the assembled, editable detective, authored through the official Blender MCP in Blender 5.2.1. Separate studio scene preserves the user's pre-existing scene. Uses a continuous shoulder-to-hem coat shell with broad planar surfaces, integrated lapel faces, a seated fedora, a nose built into the face topology, plain sleeves, oversized shoes and a cigarette. Raised pockets, buttons, belt pieces, ears and duplicate cuffs have been removed. Character refinement adds shallow overlapping front panels and collar breaks, cheek/jaw planes, a small fedora dent, a six-sided cigarette and a recognizable revolver with a simple palm. The resting pose has staggered feet and a tucked gun elbow; the weight shift fades during locomotion. No downloaded model or textures.
- `detective-bind.json`: standing transforms exported from `shared/body.js`; rendering, hits and the Blender assembly share these dimensions. `../client/assets/detective-meshes.js` contains flat triangles with monochrome material groups. The cigarette is cosmetic and excluded from hit boxes. Pooled world-space smoke stops emitting on death.
- `../scripts/make-detective.py`: reproducible detective mesh authoring and export. Regenerate the bind file with `node --input-type=module -e 'import {bodyParts} from "./shared/body.js";import {writeFileSync} from "node:fs";writeFileSync("art/detective-bind.json",JSON.stringify(bodyParts("stand",0,0,true),null,2)+"\n")'`, then execute the Python script with Blender MCP (`runpy.run_path`). It creates a new scene and saves a copy to `art/detective-noir.blend`. The detective uses its own meshes and materials; sculpture/decoy assets are unchanged.
- `../scripts/make-noir-assets.py`: reproducible source for the Blender scene, runtime geometry module; also invokes the audio generator.
- `../client/noir.js`: original canvas exhibition prints and instanced skylight strips.
- `../client/assets/`: generated runtime meshes and heel, revolver, plaster and bell sounds. Build copies these into `dist/client/assets`.

No third-party meshes, recordings, fonts or textures were downloaded. Meshes, prints and procedural effects are project-authored. Closing speech is synthesized using installed Microsoft desktop voices, not a project-authored voice or an actor recording; see `announcements.json` for exact voices and text. Rebuild using Blender's background mode and the generator script. Browser users do not need Blender.

The runtime uses connected shoulder/elbow and hip/knee chains, with walking blend and pose transitions shared by rendering and hit detection. Detective rendering remains segmented. Anonymous figures now use one closed deforming surface with connected shoulder sockets, a split pelvis, shared elbow/knee rings and continuous ankles; all intact decoys and the killer use the same topology and material. The articulated parts remain hidden drivers and approximate hit volumes. Meshes fit the existing unit hit bounds; killer and decoys share templates and materials. Printed figures are decorative. Collision still uses oriented boxes, including approximate heads. The `.blend` stores unit templates (overlapping at the origin); select a named object and isolate it to edit. Re-export changes through the generator or extend its profiles.

Footsteps (three variants), gun, breakage (two variants), bell and the stereo room impulse are generated by `python scripts/make-noir-audio.py`. Breath, heartbeat and room noise remain Web Audio synthesis. Run `powershell -File scripts/make-announcements.ps1` on Windows with the voices listed in `announcements.json` to regenerate the English closing WAV. The runtime adds a band-limited loudspeaker effect and restrained convolution reflections. The broadcast stays English regardless of UI language. The old Chinese WAV is retained only as an unused historical asset. Missing speech WAVs fall back to English browser TTS, or just the bell if speech is unavailable. The impulse is synthetic and shared across rooms, not measured acoustic simulation. Final performed voice acting, motion capture and multiplayer balance remain open.

Gameplay constraint: wall surfaces must remain uninterrupted and monochrome. Do not add contrasting skirting, wainscoting or trim. Daylight shading uses no ambient fill and a shared linear-light shadow floor of 0.028 for characters and architecture; never highlight the local killer independently.


Copy direction: restrained gallery notices and brief noir observations. In-round messages describe the immediate event; exact timings and recovery rules belong in Field Notes. Keep keys, room codes and connection errors legible. Atmospheric copy must not imply a real opponent is watching when the game has not established that. Match Chinese and English meaning without forcing literal translation.

Anonymous sculpture revision: `client/sculpture-surface.js` builds the connected surface from Blender-authored `client/assets/sculpture-profiles.js`. Regenerate profiles with `scripts/make-noir-assets.py` through Blender MCP (runpy, without the main flag, avoids audio regeneration); run `node scripts/export-sculpture-poses.js`, then run `scripts/make-sculpture-preview.py` through MCP to save the exact posed runtime surfaces to `art/anonymous-sculptures.blend`. `art/sculpture-poses.json` is the intermediate pose export. No facial features, fingers, costume, torch, tablet or discus are modeled.

The shared pose library contains David-style contrapposto, a Discobolus-inspired coiled stance and Liberty's asymmetric raised-arm gesture. Pose references: [Accademia David](https://www.galleriaaccademiafirenze.it/en/artworks/david-michelangelo/), [British Museum Discobolus](https://www.britishmuseum.org/collection/object/G_1805-0703-43), [NPS Liberty](https://www.nps.gov/stli/learn/statue-of-liberty-facts.htm). These are simplified posture studies, not anatomical replicas. The authoritative game state selects the next pedestal pose; preview and entry use that same selection, and the next entry gets a different choice. Bench and wall interactions keep their contextual poses.

Additional parody poses: Thinker (low crouch with chin supported), Winged Victory (arms stand in for absent wings), and Venus (arms concealed behind the body). These deliberately adapt the originals to the same intact anonymous figure, without props or anatomical detail. Reference pages: https://www.musee-rodin.fr/en/musee/collections/oeuvres/thinker and https://www.louvre.fr/en/explore/the-palace/ideal-greek-beauty and https://www.louvre.fr/en/explore/the-palace/a-stairway-to-victory . The shared random pool now contains six poses. The studio preview shows the three newest additions; the JSON export retains all poses.
`nDetective attitude: 7-degree downward nod, 10-degree glance toward the gun side, asymmetric shoulder line and subtle chest lean. The free foot steps forward 16cm while body mass shifts toward the supporting leg; asymmetry fades into locomotion. Head and fedora rotate together around the neck. Shared inverse hit transforms and death interpolation now support local Y rotation. The coat volume has extra depth for the forward leg.
