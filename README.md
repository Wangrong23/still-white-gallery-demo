# STILL / 别动

**The White Gallery / 白厅 — 双人非对称捉迷藏 Web Demo。**

1934 年。市政会计死在家中。那天下午，白厅照常开放。

一人扮演警探，搜寻展品里藏着的人；另一人扮演来客，静止、屏息，趁视线移开时换位。太阳逐渐下降，阴影随之移动。日落之后，警探仍可追捕，但也可能遭到近身伏击；双方都可以抢先从南门撤离。

项目使用 **Three.js + 原生 JavaScript ES Modules + Node.js WebSocket**，是可运行的玩法切片。需要 WebGL 2，支持桌面键鼠及基础手机触控（真机验收待完成）；没有账号、匹配大厅或正式 NPC 系统。游戏界面使用“来客”，内部角色标识仍为 `killer`。

## 启动

安装 Node.js 22 或更新版本，在项目目录运行：

```sh
npm ci
npm start
```

浏览器打开 **http://localhost:5000**。推荐桌面 Chrome / Edge，开启硬件加速。运行资源随服务器提供，不依赖外部 CDN。也可以使用 `pnpm install --frozen-lockfile` 和 `pnpm start`。

### 单人演练

选择角色，点击“单人演练”。另一角色由简单的开发陪练控制。`Tab` 切换角色；`F9` 停止陪练，便于手动摆放双方复现场景。单人暂停菜单会暂停计时。

**快速验证藏身：** 进入单人演练后按 `F10`，来客放到中央展台并静止，陪练关闭。

1. 按 `F3` 推进 45 秒，重复观察人物、展台与地面阴影；太阳高度从 60° 下降到 7°，方位横移 108°。
2. 按住 `Space` 屏息，释放后恢复；耗尽时观察更大、更急促的身体起伏。
3. 按移动键离开展台。准备期和白天停步 0.6 秒后自动站定；靠近墙面或特殊藏点，查看姿势预览并按 `F` 入位。
4. 比较来客在日光和环境阴影中的本机显示，再用 `Tab` 切换警探观察同一位置。
5. `F4` 播放完整闭馆过渡，或 `F6` 直接进入夜晚；寻找南门，警探可用 `F` 开手电。

### 双人联机

1. 启动一个服务器，两位玩家访问同一个网址。
2. 第一位选择角色并点击“创建房间”，获得 6 位房间码。
3. 第二位输入房间码加入，自动获得另一角色。
4. 两人到齐后开始 15 秒准备期，仅来客能行动。
5. 结束后，双方都点击“再入展馆”才会重开。

本机可开两个浏览器窗口测试。局域网使用服务器电脑的 IP，例如 `http://192.168.1.20:5000`。只有服务器电脑需要 Node，另一位只需要浏览器。联机暂停菜单不会停止对局；服务器发现掉线后会暂停双方，保留房间 30 秒等待恢复，详见“联网与恢复”。

## 当前玩法

### 静止、伪装与呼吸

- 地图包含白厅、雕塑厅、西 / 东画廊、天窗厅和入口区域。12 个预设藏点之外，还可在可达的普通墙面贴墙。
- 静止锁定身体朝向和姿势，观察仍可自由转动；身体和影子继续存在。移动解除静止。特殊姿势以 0.3 秒平滑入位，位置、动画和命中共用权威过渡状态；墙体、障碍和占位会阻止入位。
- 靠近可达藏点显示仅来客可见的半透明姿势预览。展台使用六种经典雕塑姿势：大卫、掷铁饼者、自由女神、思想者、胜利女神、维纳斯。服务器随机选择，预览与实际入位一致，下一次选择不同姿势；墙边与长椅保留对应动作。
- 按 F 贴墙或进入特殊姿势后，镜头从正常约 3.05 米平滑拉远到 3.75 米；遇障碍仍会缩近。离开展台优先回到进入前的安全位置。
- 普通呼吸产生轻微身体起伏；屏息平滑停在当前姿态，释放后平滑恢复。耗尽时起伏更大、频率更高，并随冷却逐渐平复。画面、命中和网络同步使用同一呼吸位移。
- 屏息最多 15 秒，剩余 3 秒预警。释放 1 秒后开始回气，空条回满需 12 秒。耗尽后冷却 5 秒，期间不回气；必须松开空格，冷却结束且恢复至少 3 秒气量后才能重新按下。持续按住不会自动重试。
- 警探靠近且朝向、视线构成威胁时，符合条件的来客收到屏息提示；警探看不到对手呼吸条。

### 光照与藏身反馈

实时太阳阴影覆盖人物、屋顶条带、天窗结构和隔墙。日间没有环境补光，人物与建筑共享暗部下限；白昼最后一分钟逐渐变暗，闭馆平滑进入夜晚，已取消瞬间全屏黑屏。

**白天只有来客本机模型被环境阴影遮住的部分显示半透明“幽灵轮廓”，受光部分保持实体。** 判定使用仅包含场景遮挡物的日光深度图，排除角色自阴影，避免背光面或深色材质导致全程透明。警探眼中的来客与普通雕像继续使用正常材质和遮挡，自己的辅助轮廓不会展示给对方。

夜晚保留来客本机模型的微弱自发光，帮助辨认自身，不照亮环境。当前几何边线为固定灰色，没有随阴影反色的效果。

### 搜寻、日落与结算

警探有四发子弹，误射消耗一发并让日落提前 25 秒。命中根据当前姿势的分部包围盒和场景遮挡判定；假人中弹碎裂，残骸保留到本局结束，之后不再阻挡移动、视线和子弹。弹孔只生成在实际命中的静态表面。

白天可检查 1.7 米内的人形：站定、持续瞄准并按住 E，正常呼吸的来客约 1.2 秒被识破，屏息来客与假人约 3.6 秒完成检查。检查不耗子弹，屏息只能拖延；移动、松手、移开视线或目标离开都会中断。

白昼 300 秒，闭馆过渡 2.4 秒，随后有 45 秒夜晚。剩余子弹带入夜晚；警探可射击、开手电或从南门撤离，来客可近身伏击或从南门脱身。任一方成功撤离即结束本局。

| 内部结果 | 结束原因 | 获胜方 |
| --- | --- | --- |
| `DETECTED` | 来客被射中或检查识破 | 警探 |
| `FOUND YOU` | 警探被近身袭击 | 来客 |
| `ESCAPED` | 警探从南门撤离 | 警探 |
| `KILLER ESCAPED` | 来客从南门脱身 | 来客 |
| `SURVIVED` | 支援抵达时警探仍存活 | 警探 |

来客中枪、警探被反杀会出现红色血迹与倒地过程，结算面板等待倒地展示后出现；检查识破不播放死亡。倒地姿态从受击时的动作开始，不是完整物理布娃娃。

五种结果各有双方专属的中英文文案。胜负和结束原因独立标明，正文只呈现当前角色的感受，不揭示纸张内容、人物罪责或警局关系。开场与阶段提示使用同一故事背景；开发底稿见 [docs/NARRATIVE.md](docs/NARRATIVE.md)。

## 美术、声音与设置

人物强调受控的大平面。来客和完整雕像共用无五官的连续变形表面，减少关节小人感；经典雕塑只借姿态，不添加火炬、圆盘等道具。警探保留礼帽、风衣前襟与翻领、脸部大形、左轮和香烟，以低头、向持枪侧偏转、肩线高低差、重心偏移及前后脚建立站姿；这些不对称动作在行走时减弱。

场景以 Toon 材质、硬阴影、几何边线、纸噪声和稀疏笔触统一风格，墙面保持纯色且无踢脚线。模型与画作为项目原创；Blender 源文件和再生成方法见 [art/README.md](art/README.md)，玩家运行游戏无需 Blender。

音频按 **JAZZ → SILENCE → PULSE → SILENCE** 推进。脚步和喘气有距离衰减、左右声像和隔墙低通；警探不播放自己的呼吸声，附近对手的喘气仍可听见。音乐不会利用隐藏的敌方位置或身份给警探提示。

鞋跟、左轮、石膏碎裂、钟声等使用原创生成音效；音乐、真人呼吸、喘气、心跳和远处警笛包含已导入的 CC0 资产，不能再笼统视为全部原创合成。闭馆广播使用 Microsoft 系统声音预生成的英文 WAV，无论界面语言都播英文，失败时回退浏览器语音。系统、资源来源和许可证见 [docs/AUDIO.md](docs/AUDIO.md) 与 [音频许可证](client/assets/audio/LICENSES.md)。

主菜单与暂停菜单提供中英文、总音量、环境底噪、语音开关、鼠标灵敏度、纵轴反转和标准 / 性能渲染设置，保存到当前浏览器。性能模式降低渲染分辨率，保持藏身规则；总音量为零也关闭广播。返回菜单会停止声音，重连不重播旧事件。

## 联网与恢复

服务器以 30 Hz 权威模拟，约 20 Hz 发送快照。客户端发送输入与动作，不直接决定位置、命中或胜负。本地角色已有移动预测与输入确认后的重演校正，最多预测约 0.5 秒；远端使用 100ms 快照插值。

连接中断后自动尝试恢复原房间和原角色；刷新当前标签页也可恢复。服务器发现掉线后保留房间 30 秒，等待期间暂停双方模拟与计时；位置、弹药、屏息和残骸保留。恢复后点击继续接管操作。

恢复凭据在当前标签页的 sessionStorage 中，不进入公共快照。主动离开、恢复期限届满或服务器重启后不能恢复。房间保存在单进程内存，不支持跨实例或重启恢复。

```sh
npm run check
npm test
npm run build
```

构建生成 `dist/` 浏览器资源；完整联机部署需要整个 Node 项目，不能只部署 dist。

自动测试覆盖规则、藏点与姿势过渡、共享动作和命中、屏息耗尽、死亡、音频信息边界、Host / Join、重连、重开、预测及资源服务。最近一次完整运行通过 81 项测试；此后的文案更新另检查了两种语言、五种结果、双方角色的 20 个结算组合并通过构建。本文整理未重新运行游戏测试。

`node --test tests/prediction.test.js` 可复现约 100 / 200 / 350ms RTT 的双客户端 WebSocket 延迟注入测试。这是本机消息延迟注入，不等同跨公网双机浏览器验收。浏览器检查记录与历史限制见 [docs/VALIDATION.md](docs/VALIDATION.md)；其中早期条目记录当时行为，当前规则以代码及本文为准。

## 公网部署

服务器支持 `PORT`（默认 5000）和 `HOST`（默认 `::`，IPv4 + IPv6）。使用提供 HTTPS + WebSocket 的 Node 主机时，客户端自动连接 `wss://当前域名/ws`。项目附带 `Dockerfile` 和 `render.yaml`。

```sh
docker build -t still .
docker run --rm -p 5000:5000 still
```

也可在长驻 Node 平台使用构建命令 `npm ci --omit=dev`、启动命令 `npm start` 和健康检查 `/health`。反向代理必须支持 WebSocket Upgrade。

原型部署使用单实例；多实例需要房间路由和共享状态。尚未完成持续公网服务的验收，本机 / 局域网地址不是永久公网地址。GitHub Pages 等普通静态托管不能运行权威 WebSocket 服务器。

## 手机浏览器操作

菜单和房间码输入保留浏览器原方向。触屏对局自动使用横向游戏容器：浏览器仍是竖向时旋转画布、HUD 与触控层；系统旋转使窗口变横后，取消额外旋转。无需浏览器支持方向锁定，浏览器工具栏和系统键盘不参与旋转。设置弹窗保持浏览器原方向。

- 左侧摇杆移动，向上推远进入短跑；松手后沿用自动站定。右侧空白区域拖动观察，支持同时移动和操作按钮。
- 警探：点击举枪切换瞄准、点击开火；按住检查或回头，夜间显示手电。来客：可用位置显示姿势按钮，按住屏息，夜间显示袭击。
- 旋转、暂停、切后台、系统取消触控时释放输入；旋转后需重新按下操作。联机计时规则保持不变。
- 现有灵敏度和纵轴反转同时影响触控观察。设备较慢时可在设置选择“性能优先”。目前未加入辅助瞄准、自动识别或手机专用藏身规则。

已完成桌面 Chromium 内嵌真实游戏的尺寸/合成多指回归；尚未完成 iPhone Safari、Android Chrome 真机及其他内置浏览器的完整对局验收，不能视为所有手机均已适配。

## 已知限制与下一步

- 来客使用连续变形表面，警探仍是分部动画；都不是完整骨骼蒙皮系统。命中使用分部定向包围盒，头部、衣物轮廓和倒地仍有近似。
- 场景占位会阻挡移动、姿势路径与镜头；枝叶、挂钩和环形装饰没有精细物理 / 弹道碰撞。没有完整布娃娃、屏幕空间排线或逐房间声学模拟。
