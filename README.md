# STILL / 别动

**The White Gallery / 白厅 — 双人非对称捉迷藏 Web Demo。**

凶手静止后成为展览的一部分，但实体、光照与影子始终存在。太阳慢慢下降，阴影改变，凶手需要趁警探离开视线时换位。日落之后，猎人与猎物交换身份。

这是可运行的玩法 Vertical Slice，使用 **Three.js + 原生 JavaScript ES Modules + Node.js WebSocket**。没有 Electron、账号、匹配大厅或 NPC 系统。需要桌面键盘、鼠标及 WebGL 2。

## 启动

安装 Node.js 22 或更新版本，在项目目录运行：

```sh
npm ci
npm start
```

浏览器打开 **http://localhost:5000**。推荐桌面 Chrome / Edge，开启硬件加速。依赖随服务器提供，不依赖外部 CDN、字体或图片。

也可以使用现有 pnpm：

```sh
pnpm install --frozen-lockfile
pnpm start
```

### 单人演练

选择阵营，点击 **ENTER THE GALLERY**。另一角色由简单的开发陪练控制。`Tab` 随时切换角色；`F9` 停止陪练，可以手动摆放双方复现情景。单人暂停菜单会暂停计时。

**最快验证核心玩法：** 进入单人演练，按 `F10`。

1. 凶手吸附到中央三座展台的中间，进入 STILL；陪练自动关闭。
2. 按 `F3` 推进 45 秒；重复几次，比较身体、展台和地面的影子。太阳高度从 60° 下降到 7°，方位横移 108°。
3. 按住 `Space` 看呼吸停止；释放后恢复。
4. 按 `E` 离开展台，移动至其他藏点，查看姿势预览后按 `F`；任意地面可按 `E` 原地静止。
5. `Tab` 切换警探；`R` 快速回头，左键射击。
6. `F4` 完整播放闭馆过程；也可 `F6` 直接进入夜晚。夜间寻找南侧入口，`F` 切换手电。

### 双人 Host / Join

1. 启动**一个**服务器，两位玩家访问同一个网址。
2. 第一位选择阵营并点击 **HOST**，获得 6 位房间码。
3. 第二位点击 **JOIN**、输入房间码，自动获得另一阵营。
4. 两人到齐后自动开始 15 秒准备期；仅凶手能行动。
5. 游戏结束后，双方都点击 **ANOTHER ROUND** 才会重开。

本机可开两个浏览器窗口测试。局域网使用服务器电脑的 IP，例如 `http://192.168.1.20:5000` 或 `http://[2001:db8::1]:5000`。只有启动服务器的电脑需要 Node；另一位只需要浏览器。联机菜单不会暂停服务器，掉线会结束房间并提示重连，不会伪装为正常游戏。

## 已完成的玩法

- 白厅、雕塑厅、画廊 A / B、天窗区域、入口走廊；白墙、展台、雕塑、画框、长椅、展柜、柱、盆栽、衣帽架及抽象作品。
- 任意可站立地面均可按 E 原地静止，保留位置和朝向；12 个特殊姿势点提供贴墙、双手贴身、坐、蜷缩、蹲、展开双臂及雕塑姿态等选择。靠近可达藏点会出现仅凶手可见的半透明预览，按 F 使用。
- 特殊姿势以 0.3 秒插值平滑入位，位置、姿势及命中共用权威过渡状态；墙体或被占用目标阻止入位。STILL 锁定朝向和姿势、闭眼、隐藏嘴巴、停止移动；E 或重新按移动键解除。离开展台优先回到进入前的位置，被占用则寻找同侧可达安全位置。**没有透明、隐藏身体、关闭投影或警探不可见规则。**
- 实时 DirectionalLight 阴影。天窗、屋顶条带和隔墙也参与投影；天然假线索与凶手使用相同光照系统。
- 默认 5 分钟白昼；误射消耗子弹并推进 25 秒；弹尽后仍可近身检查抓捕；剩余子弹带入夜晚。白天瞄准 1.7 米内的人形，站定按住 E 检查：正常呼吸的凶手约 1.2 秒暴露，持续屏息的凶手和假人约 3.6 秒完成检查；不耗子弹。屏息只减慢进度，不清空进度，无法无限拖延抓捕。松手、移动、移开瞄准或目标离开均会中断；夜晚只能射击或逃生。
- 基于可见姿势的身体分部射线命中、墙体和雕塑遮挡；命中立即 DETECTED。
- 藏点移动警戒：Q 布置 / 取消，45 秒内附近移动或进出会报警；最多 3 处。触发位置显示 5 秒后消失，不追踪敌人，日落时清除。静止不会触发警报。
- 假人中弹立即碎裂，检查也能排除；残骸保留到本局结束，碎裂后不再阻挡移动、视线和子弹。弹孔只在实际命中的静态表面生成；射向空中、假人或凶手不会留下悬空弹孔。
- 快速回头；正常移动的摆臂、睁眼与嘴巴。
- STILL 轻微呼吸；屏息让呼吸平滑停在当前姿态，恢复时平滑启动。动画与命中共用权威呼吸位移，联机插值也同步该位移。
- 屏息最多 15 秒，剩余 3 秒时凶手 HUD 显示预警。松开后等待 1 秒才回气，空条回满需 12 秒；耗尽后强制冷却 5 秒，冷却期间不回气。耗尽或过早尝试后必须松开空格；冷却结束且气量至少 3 秒后才能重新按下使用。持续按住不会自动重试。
- 喘气声在约 8 米内衰减，隔墙音量降至 12% 并低通处理。警探看不到呼吸条与低气量预警。
- 基于方向、距离和墙体遮挡的紧张反馈；凶手心跳、轻微黑边；双方脚步有距离衰减和左右声像。
- 闭馆钟声、英文闭馆广播（预生成 WAV，加载失败回退系统语音）、关灯声及约 0.4 秒全屏 blackout；之后进入 45 秒夜晚。
- 夜间锥形手电、凶手更快、近身袭击、入口逃生；DETECTED / FOUND YOU / ESCAPED 结算。
- 夜间计时耗尽且警探仍存活，Demo 明确定义为 **SURVIVED / 警探胜利**。
- HOST / JOIN、阵营分配、服务器权威输入模拟、位置/朝向/STILL/姿势/太阳/弹药/事件/阶段/结果同步、断线提示、双方确认重开。

状态：`PREPARATION → DAY → SUNSET → NIGHT → GAME_OVER`，击杀可直接终结 DAY / NIGHT。客户端发送输入与动作，不发送可以直接应用的位置、命中或胜负。

主要默认值：准备 15 秒；白昼 300 秒；闭馆过渡 2.4 秒；夜晚 45 秒；弹药 4；误射惩罚 25 秒；屏息 15 秒。修改 `CONFIG` 后重启服务器并刷新客户端。

## 公网部署

服务器支持 `PORT`（默认 5000）和 `HOST`（默认 `::`，IPv4 + IPv6）。通过提供 HTTPS + WebSocket 的 Node 主机部署，客户端会自动使用 `wss://当前域名/ws`。项目附带 `Dockerfile` 和 `render.yaml`；不需要另填 API 地址。

```sh
docker build -t still .
docker run --rm -p 5000:5000 still
```

可以在支持 Docker / 长驻 Node 进程的平台连接这个 GitHub 仓库，构建 `npm ci --omit=dev`，启动 `npm start`，健康检查 `/health`。反向代理必须支持 WebSocket Upgrade。

房间保存在一个进程的内存中。MVP 部署**一个实例**；重启丢失对局，多实例需要房间路由与共享状态后才能使用。尚未实际部署公网服务；本机或局域网网址不是永久公网地址。GitHub Pages / 普通静态托管无法运行这里的权威 WebSocket 服务器。

## Placeholder 与已知限制

- 角色已替换为 Blender 制作的低多边形石膏人像和风衣警探，共用肩肘、髋膝关节链，加入走停和起身过渡；仍非完整骨骼蒙皮角色。命中沿用分部定向包围盒，头部和轮廓使用盒近似。
- 目前用 Toon 材质、硬阴影、几何边线、纸噪声和稀疏地面笔触统一风格；没有屏幕空间 Sobel、完整排线着色或专用手绘动画。天窗是开放屋架与局部顶板。
- 盆栽、衣帽架和抽象雕塑已有共享的落地占位碰撞，阻挡移动和姿势路径；第三人称镜头也会避让其可见网格。枝叶、挂钩和环状雕塑尚无精细弹道/物理碰撞，装饰不会生成悬空弹孔。
- 鞋跟、左轮、石膏碎裂、闭馆钟声已使用原创 WAV 资产；呼吸、心跳、底噪保留运行时合成。脚步和喘气已有距离、视角声像与墙体低通衰减；WAV 音效已有短混响，脚步有三种变化、碎裂有两种变化；尚未按各房间几何模拟声学或绕射。闭馆英文广播使用 Microsoft 系统声音预生成的 WAV，加入旧扩音器处理；加载失败回退浏览器 TTS，尚无人声演员录音。
- 陪练只验证局部循环，无法代替真人的记忆与心理博弈；没有 NPC 系统。
- 联网是单进程权威原型，30 Hz 模拟 / 约 20 Hz 快照。已增加 100ms 快照插值缓冲以消除逐快照跳动；已支持断线自动重连和当前标签页刷新恢复；已接入本地移动预测与输入确认后的重演校正；尚无射击延迟补偿、完整反作弊。快照包含双方位置，面向可信的双人试玩。
- 5 分钟太阳曲线已可观察到真实阴影变化，但藏点安全窗口、地图绕行时间及夜间逃生平衡尚需真人多局调参。
- 已有中英文基础设置：总音量、环境底噪、语音开关、鼠标灵敏度、纵轴反转、标准/性能渲染分辨率，自动保存到当前浏览器。仍无可视化按键重绑、手柄、触摸操作及完整移动端调校。

## 1930s 黑白美术资产

已接入石膏人像、风衣与礼帽警探、左轮细节、装饰艺术海报和天窗条带；墙面保持纯色、无踢脚线。凶手与假人共用模型和材质，保留原有呼吸与姿势机制。HUD 警戒和低气量使用黑白反差及文字反馈。日间取消环境补光，材质暗部使用共享的深灰下限，人物与背景在完整遮光处融合；露出阴影的受光部位仍会显现。

模型、画作和程序生成音效均为项目原创；广播 WAV 使用本机 Microsoft 合成声音生成，无需玩家安装相同声音。Blender 源文件与再生成方法见 [art/README.md](art/README.md)。当前仍保留分部关节动画、包围盒命中和合成人声等明确限制。


## 基础设置与空间反馈

主菜单底部和暂停菜单都可打开“设置”。总音量为 0 时同时关闭音效、底噪和语音；环境底噪可单独调整。关闭设置不会自动恢复暂停的演练，联机对局仍继续计时。性能模式只降低渲染分辨率，保持当前阴影贴图与藏身规则。

隔墙脚步会降低音量并滤去高频，门洞方向保持通畅；左右声像随观察方向变化。返回主菜单会停止当前声音和闭馆播报，避免下一局重新响起。盆栽等落地实体的占位碰撞与陪练寻路共用服务器规则。


## 断线恢复

连接中断后自动尝试恢复原房间和原角色；刷新当前标签页也会恢复。服务器发现掉线后保留房间 30 秒，等待期间暂停双方模拟和计时，重连成功后继续原局。位置、弹药、屏息、残骸和警戒状态保留；点击“继续”重新接管操作，不重播旧音效。

恢复凭据保存在当前标签页的 sessionStorage，不包含在公共对局快照中，单凭房间码不能占用保留角色。主动返回主菜单或点击“离开房间”结束原房间；超过恢复期限或服务器重启后无法恢复。房间仍只保存在单进程内存中，未实现跨实例或重启恢复。


藏身调整：停止移动 0.6 秒后自动站定（准备/白天），无手动站定切换，移动立即解除；F 可在附近墙面贴墙，避开墙角和障碍。呼吸振幅调整为 0.016 米，双方共享权威动作与命中。广播无论界面语言均使用英文；白昼改为 300 秒，误射仍提前 25 秒，夜晚仍为 45 秒。

凶手已取消 E 手动站定：准备和白昼停步 0.6 秒后自动进入，移动解除；F 仍用于贴墙和特殊姿势。警探 E 检查保留。


故事背景：1934 年美国城市，市政会计遇害、付款账页失踪，警探追随灰衣人进入白厅。双方开场各自呈现线索；英文展览海报暗示六件人像与未到场的接头人，结局留下警局涉案的悬念。误射惩罚试调为 25 秒，四次共推进 100 秒；白昼仍为五分钟，尚需真人对局确认平衡。
